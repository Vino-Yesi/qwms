Wms - structure:

Frontend:
  React + TypeScript
  Realtime WebSocket client
  Accessible UI
  Virtualized tables
  Role-based dashboards

API Layer:
  API Gateway
  OAuth2/OIDC
  Rate limiting
  OpenAPI contract
  WebSocket gateway

Domain Services:
  OMS
  Inventory
  WMS
  TMS
  Notification
  Analytics
  Audit
  Integration Hub

Data:
  PostgreSQL for transactional data
  Redis for cache/queue locks
  Kafka/RabbitMQ for events

Connectors:
  Ozon
  Yandex Market
  Wildberries
  ERP (1C/SAP/NetSuite/etc.)
  TMS/carriers
  AMR/WCS if needed

Security:
  MFA
  RBAC
  Audit logs
  Encrypted secrets
  Idempotency
  Webhook signature validation
  Least privilege service accounts

Operations:
  Prometheus
  Grafana
  Sentry
  OpenTelemetry
  Dead-letter queues
  Replay tools
  Reconciliation dashboards.
